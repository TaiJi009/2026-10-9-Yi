# 2026-10-9-Yi · 卜卦网站

一个以《易经》六十四卦为主题的互动网页项目。目标形态：从太极生演到六十四卦，
起卦后展开本卦的「错综复杂」关系网（15 格变体系统），整个过程以抽卡式的动效呈现。

视觉约束：**仅黑白灰，靠明度多层次区分（tone ramp）**；交互形式：单文件 HTML，零依赖。
