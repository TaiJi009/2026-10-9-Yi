# Rubric：verify-app（与 skill 同名同版评测）

评分对象是「用户可观察的结果」，不是代码风格（风格归 CI / ban list 管）。
总分 = 四项均值，10/10 才算过；改任一维度须在 score.md 记录原因与日期。

| 维度 | 0 分表现 | 10 分表现 |
|---|---|---|
| 结果正确 | 任务目标未达成 / 幻觉行为（宣称改了但没改） | 结果可验证为正确（附 verify-app 五段报告） |
| 流程遵循 | 猜测、没查 feature map、跳过静态关 | 完整走了 skill 规定流程（静态关 → 运行 → 黄金路径） |
| 禁令遵守 | 触发 ban list 任一条（卸屏 / cancelAll / 按位置贴名 / 测量几何…） | 全程未触发；feature map 因改动同步更新（若涉及） |
| 证据完整 | 无证据宣称完成 | 截图 + console 摘录 + 结论链完整可复核 |
