# 屏 5 · 错综演算（network）

- **是什么**：三栏对照 + 展示位。左列 6 张变卦（上→下 = 上爻→初爻，垂直位置 = 变哪一爻）；
  顶排综/错/交；右列互卦 5 张（互·去初 … 互·去五上）。本卦与展示位同行等宽，展示位默认显示**之卦**。
- **用户如何到达**：屏 4 点「展开错综 · 十五卦」。
- **怎么用**：点击任一卦卡，展示位当场演算那种变法：
  | 点击 | 展示位行为 |
  |---|---|
  | 变卦 | 本卦平移到展示位 → 对应一爻翻转 |
  | 错卦 | 平移 → 六爻同时翻转，逐爻错峰 |
  | 综卦 | 平移 → 整卦旋转 180° |
  | 交卦 | 下卦移上、上卦移下，两条反向弧错身 |
  | 互卦 | 本卦上框选保留区间 → 展示位淡显 → 裂变成两个三爻卦叠加 |
  点新卡时展示位旧卦先淡化消失，新卦再出现。可「重新起卦」回屏 0。
- **代码位置**：控制器 `stage/stage.ts` + 变体参数 `stage/variants.ts`；展示位是**复制**不是移动本卦
  （本卦必须原地不变，复制体是覆盖在上面的独立爻栈）。
- **自动化定位**：`section[data-screen="network"]`；卦卡选择器待验证。
- **硬约束**：本卦框与展示位框**同行、等几何、固定 gap**——平移量 dx/dy、交卦错身 ±3×(爻高+间距)、
  互卦源↔目标 y 映射全是依赖它的常数；两框几何一变，公式全废。
- **已知坑**：**连点绝不可用 `ANIM.cancelAll()`**（切屏解药，会杀卡片入场尾帧）——只用局部
  `SHOW.seq` + `cancelGuest()`；互卦的裂变是参数化的（源只有 4-5 个不同下标，一个源供两个目标时
  该爻裂成两条——这是视觉来源，不是 bug）。
- **待定性缺陷（eval 迭代 2 发现，未修）**：点「互」类卦卡可复现 console warning
  `Invalid keyframe value ... translateY(NaNpx)`——指向 `stage.ts` 的
  `parseFloat(getComputedStyle(...).rowGap)`：`--ygap` 只在媒体查询断点内赋值，视口在断点外时
  解析不出数字。HEAD 基线即复现，与任何改动无关；是否缺陷、如何修（改 CSS 断点覆盖 or 常量化）
  需先定性，勿顺手修。
