# 屏 4 · 成卦（settle）

- **是什么**：成卦展示——本卦 + 之卦并列，各带卦名。有动爻时之卦 = 动爻全变后的卦；无动爻时之卦 === 本卦。
- **用户如何到达**：屏 3 六爻落定后自动进入。
- **怎么用**：静态展示本卦/之卦与卦名；点「展开错综 · 十五卦」进入屏 5。
- **代码位置**：`screens/SettleScreen.tsx` + `plays/playSettle.ts`；变体计算在 `core/rules.ts`（`buildVariants` 等）。
- **自动化定位**：`section[data-screen="settle"]`；「展开错综 · 十五卦」按钮选择器待验证。
- **已知坑**：**六爻皆静时展示位留空标「无动爻」是正确行为**（之卦 === 本卦，语义坍塌），不许「修」；
  卦名入场有淡入动画（历史缺陷修复遗留的 `fill:forwards` 语义，别动）。
