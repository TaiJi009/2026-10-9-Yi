# 屏 1 · 生演（generate）

- **是什么**：点击驱动的抽卡生长——太极 → 两仪 → 四象 → 八卦，金字塔倒置（太极在下、八卦在上）。
  共 14 次点击：太极 2 次 + 每层裂变。
- **用户如何到达**：屏 0 单击太极（或 `Enter`/`Space`）。
- **怎么用**：点任一可生长节点 → 「蓄→抽/裂变→落/显」三段动画（720/560/520ms）→ 该节点上方长出新节点。
  第 2 个子节点的新爻 = 第 1 个的反（非随机）；**每层恒 2^d 个互异节点**（有专门测试断言）。
- **键盘**：可点节点均可用 `Tab` 聚焦、`Enter`/`Space` 触发；`Esc` 跳过本屏。
- **代码位置**：`screens/GenerateScreen.tsx` + 控制器 `grow/grow.ts` + 节点模型 `core/grow-model.ts` +
  尺寸/时长预算 `core/data.ts`（`GROW` 公式与 `DUR.gen*`）。
- **自动化定位**：`section[data-screen="generate"]`；节点元素的选择器待验证。
- **关键预算**（改本屏前必读）：尺寸按 `GROW` 公式预算、**不测量**：
  `x(col,d) = (col+.5)/2^d × W`、`y(d) = Y0 − d×RH`；宽度 `8×84 + 7×41 = 959 ≤ 1000`，节点再加宽到 96 就溢出。
  SVG 爻线的 `transform-box: fill-box` 不能丢（否则 `transform-origin` 跑偏）。
- **已知坑**：
  - 顶端 8 个八卦顺序是**随机**的——与屏 2 固定先天序不一致是有意为之，不许「修」；
  - 先抽出的「仪」在**左边**：左右顺序由第一抽决定，不是固定「阳左阴右」；
  - 节奏「感觉慢」是有意的：第 3 段与下一次点击并行 → 感知间隔 ≈1.1s。
