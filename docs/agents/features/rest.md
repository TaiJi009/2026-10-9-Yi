# 屏 0 · 太极呼吸（rest）

- **是什么**：站点首屏。居中一个呼吸起伏的太极图，是整个体验的奇点与入口。
- **用户如何到达**：打开站点默认即此屏。
- **怎么用**：单击太极即起卦（进入屏 1 生演）；键盘 `Enter` / `Space` 等效单击。
- **代码位置**：`screens/RestScreen.tsx`；FSM 与全局调度在 `App.tsx`。
- **自动化定位**：`section[data-screen="rest"]`；太极元素的选择器待验证。
- **已知坑**：太极的呼吸是持续动画（`fill:forwards`/CSS 循环）——验证时不要断言其静止；
  从本屏只能前进，没有回退入口（被跳过后不回来，属有意设计）。
