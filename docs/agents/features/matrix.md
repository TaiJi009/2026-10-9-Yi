# 屏 2 · 六十四卦方阵（matrix）

- **是什么**：8×8 静态方阵，全部六十四卦。行 = 上卦、列 = 下卦，行列顺序均为**先天生成序**
  （乾兑离震巽坎艮坤，即 `RULES.generationOrder()`）。第 row 行第 col 列 = `[...列首bits, ...行首bits]`（下卦在前）。
- **用户如何到达**：屏 1 完成（或 `Esc` 跳过）后进入。
- **怎么用**：静态展示；点「继续 · 起卦」进入屏 3。
- **代码位置**：`screens/MatrixScreen.tsx` + `plays/playMatrix.ts`；卦象渲染与屏 1 同尺寸（宽 84/线厚 6/间距 11）。
- **自动化定位**：`section[data-screen="matrix"]`；「继续 · 起卦」按钮选择器待验证。
- **已知坑**：本屏卦序**固定**先天序，与屏 1 的随机序不一致是有意为之；两屏卦象同尺寸是刻意的视觉连续。
